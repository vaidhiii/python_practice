# Day 5 - List Comprehensions & Built-in Functions

## 📚 Topics Covered

* List Comprehensions
* Dictionary Comprehensions
* Lambda Functions
* `map()`
* `filter()`
* `zip()`
* `enumerate()`

## 📝 Programs

1. Create a list of squares using list comprehension
2. Create a list of even numbers from 1–50 using list comprehension
3. Create a dictionary of numbers and their cubes
4. Double every number in a list using `map()`
5. Filter all odd numbers from a list
6. Zip two lists (names and marks)
7. Print index and value using `enumerate()`

## 🎯 Concepts Learned

* List Comprehensions
* Dictionary Comprehensions
* Anonymous Functions (`lambda`)
* Data Transformation using `map()`
* Data Filtering using `filter()`
* Combining Iterables using `zip()`
* Iterating with Index using `enumerate()`
