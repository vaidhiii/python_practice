# Employee Management System

A simple command-line Employee Management System built using Python. This project demonstrates the use of functions, lists, dictionaries, `**kwargs`, loops, conditional statements, and user input.

## Features

* Add a new employee
* Display all employees
* Search for an employee by name
* Menu-driven interface
* Case-insensitive employee search

## Technologies Used

* Python 3

## Concepts Practiced

* Functions
* `**kwargs`
* Lists
* Dictionaries
* Loops
* Conditional Statements (`if`, `elif`, `else`)
* User Input
* Menu-Driven Programming
