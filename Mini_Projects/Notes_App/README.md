# 📝 Notes App

A simple command-line Notes App built using Python.

## Features

- ➕ Add a new note
- 📖 View all saved notes
- 💾 Save notes in a text file
- ⚠️ Handle the case when the notes file doesn't exist

## Technologies Used

- Python
- File Handling
- Exception Handling

## Project Structure

```
Notes_App/
├── notes_app.py
└── README.md
```

## How to Run

1. Open the project folder.
2. Run the program:

```bash
python notes_app.py
```

3. Choose an option from the menu:
   - Add Note
   - View Notes
   - Exit
