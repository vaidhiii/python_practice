# 🔐 Password Generator

A simple Python program that generates a random password based on the user's desired length. The password contains a mix of uppercase letters, lowercase letters, numbers, and special symbols to create strong and secure passwords.

## 📌 Features

- User chooses the password length
- Generates a random password
- Uses uppercase and lowercase letters
- Includes numbers and special characters
- Simple and beginner-friendly Python project

## 🛠️ Technologies Used

- Python 3
- Built-in `random` module
- Built-in `string` module

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python password_generator.py
```
