# Library Management System 📚

A simple command-line Library Management System built using Python. This project demonstrates the basics of Object-Oriented Programming (OOP) by allowing users to manage a collection of books in memory.

## Features

* Add a new book
* Display all books
* Search for a book by title
* Menu-driven interface
* Handles invalid menu input using exception handling

## Concepts Used

* Classes and Objects
* Constructors (`__init__`)
* Instance Variables
* Methods
* Lists
* Loops (`while`, `for`)
* Conditional Statements (`if`, `elif`, `else`)
* Exception Handling (`try` / `except`)

## Project Structure

* **Book Class** – Stores the title and author of a book and displays its details.
* **Library Class** – Manages the collection of books by adding, displaying, and searching for books.
