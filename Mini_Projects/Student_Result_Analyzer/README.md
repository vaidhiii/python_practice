# Student Result Analyzer 📊

A simple Python mini project that analyzes student marks using Python's built-in functions and data structures.

## Features

* Combine student names and marks
* Display each student's result
* Show students scoring above 80
* Create a dictionary of student names and marks
* Find the topper

## Concepts Used

* Lists
* Dictionaries
* `zip()`
* `enumerate()`
* Loops
* Conditional Statements (`if`)
* `max()`

## Future Improvements

* Accept user input for student names and marks
* Calculate average marks
* Assign grades based on marks
* Sort students by marks
* Save results to a file
